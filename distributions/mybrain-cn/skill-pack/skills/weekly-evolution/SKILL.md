# Weekly evolution

## Job

Show how the user's current judgment changed—not how much content entered the Brain.

## Steps

1. Use `delta` and scoped recall for the week.
2. Group additions into: new evidence, changed judgment, correction, abandoned idea, unresolved unknown.
3. Preserve failure and unused material; do not equate capture with success.
4. Identify one pattern worth turning into a rule/asset and one pattern that should stay provisional.
5. Name one Monday-morning behavior change.

## Output

Lead with the largest judgment delta. Keep evidence, counter-evidence, and reversal conditions visible.
