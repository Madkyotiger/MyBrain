# Source-grounded recall

## Job

Turn stored context into a usable answer without pretending the Brain is complete.

## Steps

1. Use `recall` for facts/snippets; use `entity` for one known person/project card.
2. Prefer the smallest source scope that answers the question.
3. Separate **known**, **interpretation**, **conflict**, and **unknown**.
4. Attach source slug/provenance to every consequential claim.
5. If retrieval is degraded or empty, say so and name the next source needed.

## Output

Lead with the answer. Then show supporting evidence, visible gaps, and the next usable move. Never turn a title or thin snippet into a confident conclusion.
