# Relationship context

## Job

Restore enough history to act with continuity while respecting source and privacy boundaries.

## Steps

1. Use `entity` and scoped `recall` for the person and shared projects.
2. Separate observed facts, explicit preferences, commitments, and private interpretation.
3. Show recent interaction and changes; do not psychoanalyse silence.
4. Name trust deposits, unresolved friction, and a useful next contribution only when supported.
5. Never expose private relationship judgment into a company/client surface by default.

## Output

Context, active commitments, observable relationship signals, sensitive/private note boundary, and next useful move.
